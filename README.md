# 노글라쓰티쳐의 과학교실

수업에서 쓰는 과학 시뮬레이션입니다. 첫 화면에서 과목을 골라 들어갑니다.

- `index.html` — 첫 화면 (과목 고르기)
- `life-science/` — 생명과학 시뮬레이션 모음
  - `nephron.html` — 콩팥단위 오줌 공장
- `earth-science/` — 지구과학 시뮬레이션 모음
  - `diurnal.html` — 천체의 일주운동 시뮬레이션
  - `sun-annual.html` — 태양의 연주운동 3D 시뮬레이션
  - `moon-phases.html` — 달의 위상 변화 관찰 시뮬레이션

맨 위에 남아 있는 `diurnal.html`, `sun-annual.html`, `moon-phases.html`은 예전 주소로 들어온 사람을 `earth-science/` 안의 새 주소로 넘겨 주는 페이지입니다.

새 과목을 추가할 때는 폴더를 하나 만들고 그 안에 `index.html`(모음 페이지)과 시뮬레이션 파일을 넣은 뒤, 첫 화면에 과목 카드를 추가합니다.
